# Assignment 1 - Git, NumPy & Pandas

This repository contains solutions for Assignment 1 covering Git fundamentals, NumPy array operations, and Pandas data cleaning/analysis.

## Project Structure
- `answers/01_git_theory.md`: Theory answers for Part A.
- `answers/02_numpy.py`: Solutions for tasks B1-B10.
- `answers/03_pandas.ipynb`: Solutions for tasks C1-C12.
- `outputs/summary.csv`: Exported subject summary table.

## How to Run This Project

To set up and run this project, run the following commands sequentially in your terminal:

python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python data/make_data.py

After running those commands, open answers/02_numpy.ipynb and answers/03_pandas.ipynb in Jupyter Notebook and execute all cells.
